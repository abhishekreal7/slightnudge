# S1 — mandatory mutation authentication

Baseline proof: `S1-before-complete.log/json`; after: `S1-after.log/json` (exit 0). All negative requests use `{}` bodies so no real file or pending edit can be modified.

| Product hunk | Proof |
|---|---|
| Remove environment-provided session-token override | Synthetic test override fails baseline and is ignored after; normal token remains random, stable per server process, delivered by the existing host-validated RootLayout script/token endpoint. No token value is recorded. |
| Remove reorder-safety process-argument authentication bypass | Missing token/Origin with that argument reaches body validation before; returns 403 after. |
| Require Origin in central mutation guard | Preview, Apply and Undo with valid token but missing Origin return body-validation errors before, 403 after. Foreign Origin and wrong Host return 403 both before and after. Valid Origin/token still reaches normal validation. |
| Bind app-controlled start command to 127.0.0.1 | Dev command already binds loopback; start did not. Both script checks pass after. |

Every source-mutating route uses validateMutatingRequest. Read-only inspection POSTs do not change source and retain their existing separate contract; OPTIONS remains preflight. The existing origin allowlist permits loopback preview origins as well as the editor origin, with exact loopback Host/server-port and forwarded-host validation plus the per-session token. No missing-Origin exception remains.

RootLayout already delivers the token only for validated local hosts; no new exposure channel is added. Direct user-run Next commands can choose another interface, outside app-controlled npm scripts. Docker's host port publication is already loopback; its container-internal server must listen on the container interface. Runtime bind evidence is captured when the isolated regression server starts.

Initial loader-error logs are harness startup errors (Windows absolute ESM path needed a file URL), not product findings. Existing tests and expected results are unchanged.
