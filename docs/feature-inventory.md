### Additional limits that are easy to miss

- The image library upload is a real asset write independent of source Save. The read-only audit did not use it. Undo/discard does not garbage-collect library files.
- Inspector rendering does not guarantee source editability. The preview route rechecks ownership, exact source, transform compatibility, scope and compiler output. An enabled-looking control can still receive an intentional refusal.
- Main typography and fill controls are preset utilities. Computed/custom labels are readouts, not arbitrary CSS editors. No general CSS-module/CSS-in-JS/provider editor, multiselect/group/ungroup/component extraction, undoable general element insertion, timeline/keyframes or CMS binding was found.
- “Free move” means visual offset with flow space retained. Reorder changes sibling source order. Reparent changes container ownership. Text alignment and flex/grid alignment are different operations; none is a general canvas smart-alignment/distribution tool for multiple selections.
- The current project's theme determines actual utility sizes, fonts and generated CSS. Desktop/tablet/mobile preview width is not a separate editable page and does not independently create a breakpoint override.

For new feature work, changing W alone is not evidence that all editor surfaces agree. Changing P/A/H alone can affect numerous controls that look unrelated in the UI.

## Do not touch without a test

- **Source identities/callsite traces and selection coordinates**: require an exact under-pointer/source assertion, iframe offset + scale conversion, and a Layers fallback case. Include identical shared-component callers and covered containers.
- **P/A or specialized source ownership/refusals**: require before/after source, unchanged sibling/provider, unsupported/dynamic refusal and target project compile proof. Never relax an expected target to make a test pass.
- **H, locks, journals, source-group, Apply/Undo API contracts**: require original-byte checks, failed publication, stale external edit, interrupted operation, scoped project/file recovery and no duplicate write. Formatter tests must state whether bytes or semantic tokens are restored.
- **W draft keys/cursors/Save handlers or route/view transitions**: require project/file isolation, refresh recovery, draft Undo/Redo and one real source Save/exact Undo in both modern views and flagged legacy Studio. Preserve source versus draft Undo distinction.
- **B/C/adapter runtime protocol and DOM projection**: require current generated adapter plus a restarted temporary preview; source/DOM verification, iframe-only reload, long page, zoom and origin/session checks. Do not silently update real projects in a test.
- **Typography/inline editing/toolbar geometry**: require actual computed typography, original-size editing, native input keyboard ownership and no pointer interception over page content.
- **Effects/responsive scope/border selection display**: require exact-scope utility recognition, custom breakpoints, unaffected other scopes/neighbours, reduced-motion behavior where relevant and target Tailwind 3/4 compilation.
- **Image/action/icon/component controls**: require ownership/provider refusal, stale selection cancellation, source-backed replacement, refresh and Save/Undo; never rewrite a shared provider while claiming one-instance editing.
- **Legacy fixture overlay and setup editor**: require tests for those actual routes if they are changed. Modern W tests cannot establish their parity.

## What was not verified

No mutation suite was run during this inventory. We did not perform source edits, Apply, Undo, uploads, clipboard writes, adapter install/removal, Docker operations, public/private repo import, clean-machine installation, production build/deployment, licensing/billing/update delivery or new malicious-path experiments. No secrets or environment configuration were read.

The browser used the existing disposable runtime with local fixture content and copied lab repository metadata, not a newly imported real website. All 49 entries were traced to code/tests or explicit absence searches; not all conditional forms were instantiated with real source data. Images, icons, typed-instance and recovery dialogs rely on saved proof/code rather than fresh mutation exercise. History opened but its populated asynchronous list was not freshly qualified. The clipboard action and customer installer have no passing proof identified.

One exploratory browser inspection stopped waiting for Hover after Escape had closed the window inspector; reopening the inspector explicitly produced the successful Hover/disabled-control observation. This was an audit setup error, not a reproduced product failure. Repository setup was observed after its asynchronous metadata load. Modern completed inspections reported zero page errors; they are not the previously failed full selection regression.

Historical evidence is mixed: some real APIs, some mocked APIs, some failed runs and one appearance report without reread raw logs. Those distinctions are retained above. A WORKING bounded feature should be preserved and tested rather than reimplemented; it should not be assumed flawless across arbitrary frameworks, dynamic providers, responsive states or all current routes.
